## 3. Executive Summary

On 12 June 2024, an external host (192.168.110.1) exploited CVE-2024-4577, an argument-injection vulnerability in PHP-CGI on Windows, against the organization's Apache web server (Apache 2.4.59, PHP 8.2.19). After brief reconnaissance, the attacker sent crafted requests to `upload.php` that abused the `php://input` / `auto_prepend_file` technique to execute arbitrary PHP, achieving remote code execution. Prefetch and timeline analysis show the attacker then ran `whoami.exe` to confirm their privilege level, followed by `calc.exe`, before the activity was detected and blocked. The exploitation attempt is confirmed. The single source IP and the limited set of commands point to an early-stage intrusion rather than a completed compromise, but the server should still be treated as compromised, patched to a fixed PHP release, and reviewed for persistence.
